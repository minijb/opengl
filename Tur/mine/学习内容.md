## 事件系统

**准则** ： 所有事件都是一个 event

### 1. 基础系统

Event： 

1. 基类没有具体的操作， 只处理类型以及分类。
2. 具体的事件，保存具体需要存储的时间
3. 可以分出一层来处理 -- 分类  (输入相同/有相似部分的东西)。

额外开销：
1. 一张事件枚举类型表（具有所有的事件类型）
2. 可选：一张时间分类表

Dispatch 事件分发器 指导如何处理各种事件

```cpp
// 在 Event.h 里
class EventDispatcher {
public:
    EventDispatcher(Event& event) : m_event(event) {}

    // 模板：只匹配指定类型，传入一个返回 bool 的 handler
    template<typename T, typename F>
    bool dispatch(const F& func) {
        if (m_event.getEventType() == T::getStaticType()) {
            m_event.handled |= func(static_cast<T&>(m_event));  // |= 而非 =：一旦标记 handled 就保持，不被后续 false 清掉
            return true;
        }
        return false;
    }
private:
    Event& m_event;
};
```

`dispatch<T>` 内部用编译期 `T::getStaticType()` 比较类型，匹配则把 `Event&` 安全 `static_cast` 成 `T&`，  
调用你的 handler。**类型安全、零虚函数开销（除了初始比较）。**
